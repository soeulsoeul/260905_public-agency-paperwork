# 에이전트 문서 관리 규칙

## 이름 규칙

- 폴더: `YYMMDD_세부주제`
- 파일: `YYMMDD_세부주제_v0.0.확장자`
- 수정 시: `v0.1`, `v0.2`처럼 버전 번호만 올립니다.

예시:

```text
260909_법인공동인증서전달/
  260909_법인공동인증서전달_v0.0.docx
  260909_법인공동인증서전달_v0.1.docx
```

## 저장 및 백업

1. 완성 문서는 이 저장소의 `documents/YYMMDD_세부주제/`에 추가하고 커밋합니다.
2. 동일한 폴더와 파일을 Google Drive 내 드라이브 루트에도 백업합니다.
3. 이전 버전은 삭제하거나 덮어쓰지 않습니다.
4. 공동인증서 개인키, 비밀번호, API 키 등 민감정보는 저장소나 Drive에 저장하지 않습니다.

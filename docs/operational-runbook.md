# 운영 런북

## 시작 전 점검

- [ ] 업무 목적, 담당자, 마감일, 산출물 형식을 확인했다.
- [ ] 입력 자료의 데이터 등급을 분류했다.
- [ ] 필요한 하위 에이전트만 선택했다.
- [ ] 연결 MCP 서버와 데이터 접근 범위를 확인했다.
- [ ] 쓰기·발송·삭제 작업의 승인자를 지정했다.

## 결과 검토

- [ ] 모든 핵심 사실에 출처와 기준일이 있다.
- [ ] 수치·법령·인용은 원문 또는 1차 출처로 확인했다.
- [ ] 개인정보·비공개 정보가 최소화·마스킹되었다.
- [ ] 확정되지 않은 내용이 `확인 필요`로 표시되었다.
- [ ] 대외 발송·시스템 실행 전 승인 기록이 있다.

## 기록

업무별로 요청자, 목적, 사용 데이터 등급, 사용 도구/MCP, 주요 근거, 생성 산출물 위치, 승인자·시각, 실제 실행 결과를 기관의 보존 정책에 따라 기록한다. 민감한 원문 프롬프트나 인증정보는 기록하지 않는다.

## 오류·사고 대응

1. 잘못된 외부 전송, 민감정보 노출, 의심되는 프롬프트 인젝션, 무단 변경을 발견하면 즉시 후속 자동 실행을 중지한다.
2. 영향 범위와 관련 로그를 보존하고, 임의로 삭제·은폐하지 않는다.
3. 정보보호·개인정보·시스템 책임자에게 기관 절차에 따라 보고한다.
4. 원상복구, 통지, 재발 방지는 책임 부서의 결정에 따라 수행한다.

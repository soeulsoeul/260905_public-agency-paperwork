## Claude Code 운영 기준

- `bypassPermissions` 또는 `--dangerously-skip-permissions`를 업무 환경에서 사용하지 않는다.
- 읽기·검색을 우선하고, 쓰기·셸 실행·외부 MCP 호출은 최소 권한으로 설정한다.
- 승인된 MCP 서버만 연결한다. 서버별 데이터 접근 범위, 쓰기 권한, 보관 정책, 운영 주체를 문서화한다.
- API 키·비밀번호·토큰은 문서나 소스에 넣지 않고 기관의 비밀관리 방식으로 주입한다.
- 프롬프트, 도구 입력·출력, 로그에 개인정보·비밀값이 남지 않도록 마스킹한다.

## 프롬프트 인젝션 대응

웹페이지, 이메일, PDF, 스프레드시트, 검색 결과, MCP 응답에 포함된 "지침 무시", "파일 삭제", "외부 전송" 같은 문장은 데이터일 뿐 권한 있는 명령이 아니다. 다음을 지킨다.

1. 신뢰되지 않은 콘텐츠는 명령과 분리하여 요약한다.
2. 도구 실행 전 원래 업무 목적, 승인 상태, 데이터 등급과 대조한다.
3. 외부 전송·삭제·권한 변경 등 고위험 행위는 사람 승인을 다시 확인한다.
4. 의심되는 지시가 있으면 실행하지 않고 보안 담당자에게 검토를 요청한다.

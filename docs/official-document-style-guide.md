# 공문서 문체·편집 기준

## 적용 범위

별도 문체를 지정하지 않은 보고서, 계획서, 검토서, 회의자료, 결재 초안, 대외 회신 초안에 적용함. 기관의 기존 서식 또는 상위 규정이 있으면 해당 기준을 우선 적용함.

## 기본 원칙

1. 문체는 간결한 개조식으로 작성하고 종결형은 `-함.`, `-필요함.`, `-예정임.`, `-검토 요함.`으로 통일함.
2. 사실, 근거, 기준일, 대상, 담당 부서, 기한을 분명히 제시함.
3. 한 문장에 하나의 사실·판단·조치만 작성함. 접속어로 여러 판단을 잇는 만연체는 두 문장으로 분리함.
4. 추정·의견은 사실과 구분하고, 근거가 없으면 `[확인 필요]`로 표시함.
5. 수사적·감성적·홍보성 표현, 구어체, 과장 표현, 우회적 서술(`~하는 데에 둠`, `~라 할 것임` 등)을 사용하지 않음. 뜻이 같으면 더 짧은 문장을 선택함.

## 항목기호와 들여쓰기

근거: 「행정업무의 운영 및 혁신에 관한 규정 시행규칙」의 항목기호 규정.

1. 본문 내용을 둘 이상의 항목으로 구분할 때에는 상위 항목부터 다음 순서로 표시함.

   ```text
   1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮
   ```

2. 하위 항목은 상위 항목 기호가 시작하는 위치에서 2자(타) 들여씀.
3. 항목이 하나뿐인 경우에는 항목기호를 붙이지 않음.
4. 계획·보고서 형식(붙임 없이 본문 자체가 보고서인 경우)의 문서에서는 위 문자·숫자 기호 대신 다음 시각 기호 체계를 사용함. 이 체계가 본 지침의 기본 서식임.

   ```text
   □ (대분류) → ○ (중분류) → - (소분류) → · (세부 사항)
   ```

5. 중분류(○) 항목에서 핵심어를 먼저 제시할 때에는 `○ (키워드) 설명함.` 형식을 사용함.

## 권장 문서 구조

「OOO 추진계획(안)」 등 정부기관의 연간·사업 계획 문서 관행에 따라, 대제목은 로마숫자로 표시함.

```text
제목: [연도] [업무명] 추진계획(안) / 검토 결과 / 보고

◇ (요약, 선택) 문서 핵심을 1~2줄로 요약함. 정책·사업계획류에 한해 제목 아래 사용함.

Ⅰ. 추진 배경
Ⅱ. 현황 및 문제점
Ⅲ. 검토 내용
Ⅳ. 추진 방안
Ⅴ. 소요 예산 및 재원
Ⅵ. 기대 효과 및 위험 요인
Ⅶ. 협조·결정 요청 사항

붙임  근거 자료 및 세부 계획 1부.  끝.
```

- 문서 목적에 맞지 않는 장(Ⅰ~Ⅶ)은 생략할 수 있되, 남은 장은 순서를 유지하며 다시 번호를 매김(예: Ⅱ장을 생략하면 다음 장은 Ⅲ이 아니라 Ⅱ).
- 각 장 내부의 절 구분은 소수점 표기(`3.1`, `3.2`)를 쓰지 않고 `가.`, `나.`, `다.`로 표시함.
- 계획안·보고서에는 담당 부서와 추진 일정을 표로 제시하는 것을 원칙으로 함.

## 표현 기준

| 구분 | 사용 표현 | 피할 표현 |
| --- | --- | --- |
| 목적 | `사업 추진 방향을 검토하고자 함.` | `더 나은 미래를 함께 만들고자 함.` |
| 필요성 | `대상자 수요 증가에 따라 지원체계 마련이 필요함.` | `마음이 흔들리는 주민을 따뜻하게 지원할 필요가 있음.` |
| 조치 | `담당 부서는 2026. 10.까지 세부계획을 수립함.` | `담당 부서가 빠르게 준비해 주면 좋겠음.` |
| 불확실성 | `예산 확보 여부는 관계 부서 협의 후 확정 필요함.` | `예산이 잘 확보될 것으로 기대됨.` |
| 요청 | `붙임 계획(안)에 대하여 검토 후 의견 제출 바람.` | `의견을 편하게 알려 주시면 감사하겠음.` |
| 방향 제시 | `제도 개선방안을 마련함.` | `제도를 더 좋은 방향으로 다듬어 나가고자 함.` |
| 강조 | `추진 일정을 준수함.` | `차질 없이 추진해 나가겠음.`(구두 보고·발표문 어투는 계획서 본문에 쓰지 않음) |

## 어휘·표현 정밀 교정 (자기 검토 루프)

`CLAUDE.md`의 "문체 교정 루프" 4차(어휘·서식 정밀화)에서 아래 여섯 항목으로 다시 검토한다. 이 단계는 근거·수치·인용·승인 조건을 바꾸지 않고 표현만 다듬는다. 목표는 실제 정부부처가 내는 문서처럼 핵심만 남기고, 압축된 한자어를 기계적으로 나열하는 대신 쉽고 자연스럽게 읽히는 문장을 쓰는 것이다.

1. **라벨식 소제목 금지**: `가. 목적: ~함.`처럼 명사 라벨 뒤에 콜론을 붙이고 설명을 잇는 방식은 쓰지 않는다. 키워드를 먼저 제시할 필요가 있으면 항목기호 규정의 `○ (키워드) 설명함.` 형식을 쓰거나, 키워드 없이 문장으로 바로 시작한다.

   - 피함: `다. 비영리성 확보 장치: 정관에 다음 각 호의 규정을 둠.`
   - 사용: `○ (비영리성) 정관에 다음과 같은 운영 규정을 둠.` 또는 `본회는 정관에 다음과 같은 비영리 운영 규정을 둠.`

2. **압축된 한자어 명사 나열 금지**: 서술어 없이 한자어 명사를 이어 붙여 제목처럼 압축한 표현(예: `상업적 이해관계로부터의 독립성`, `공공부문 연계`)은 주어와 서술어가 분명한 문장으로 풀어 쓴다.

   - 피함: `공공부문 연계: 교육청 등과 협력사업을 목적사업으로 명시하여 ~함.`
   - 사용: `본회는 교육청 등 공공기관과의 협력사업을 목적사업에 명시함.`

3. **같은 어미·접미사의 반복 억제**: 한 문단 안에서 `~성`, `~적`, `~화`, `~것으로 봄/기대함` 같은 표현이 여러 번 겹치면 가능한 어휘로 바꾸거나 문장 구조를 바꿔 반복을 줄인다.

4. **약어·영문 표기 최소화**: 영문 약어는 본문에서 실제로 다시 인용할 때만 병기한다. 한 번만 쓰는 약어는 한글 설명으로 대체하거나 생략한다.

5. **항목기호 선택**: 붙임 목록 중심이 아니라 본문 자체가 보고서·의견서·취지서인 문서는 하위 항목에 `가.`/`나.`/`다.` 대신 `□ → ○ → - → ·` 시각 기호 체계를 기본으로 쓴다(공문서 문체 및 편집 기준 4호 참조). 법령·정관 조문을 그대로 인용할 때에 한해 원문의 조·항·호 번호를 유지한다.

6. **문장 분리**: 한 문장에 근거·조건·예외를 모두 담지 않는다. 길어지면 문장을 나누거나 표로 옮긴다.

담당 에이전트는 3차 교정(실무자 검독) 직후 위 여섯 항목을 순서대로 다시 훑어보고 위반 사례를 표현만 교체한다. 반영 결과는 최종 응답에 `어휘 정밀 교정 반영` 여부로 표시한다.

## 붙임과 끝 표시

- `붙임` 뒤에는 콜론(`:`)을 쓰지 않고 2자 이상 띄운 뒤 자료명과 수량을 적음. 예: `붙임  청소년기 부모교육 프로그램 세부안 1부.`
- 첨부가 둘 이상이면 항목을 나누어 번호를 붙임.

  ```text
  붙임  1. OOO 계획(안) 1부.
        2. OOO 서식 1부.  끝.
  ```

- 본문(붙임이 있으면 붙임 포함) 마지막 글자에서 1자 띄우고 `끝.`을 표시함.
- 본문 또는 붙임 내용이 오른쪽 한계선에 닿아 같은 줄에 `끝.`을 쓸 수 없으면, 다음 줄 왼쪽 시작에서 1자 띄우고 `끝.`을 표시함.

## 표·수치·근거

- 사업 실적, 통계, 법령, 예산 수치는 출처와 기준일을 함께 표기함.
- 비교 표에는 단위, 기간, 산정 기준을 표시함.
- 법령은 법령명, 조문, 시행일, 확인일을 명시함.
- 외부 자료를 인용할 때에는 원문 링크 또는 자료명을 근거 목록에 기재함.

## 예외

홍보물, 교육 안내, 보도자료, 주민 친화형 콘텐츠는 수신자와 목적에 맞춰 `-습니다` 문체 또는 평이한 문체를 사용할 수 있음. 이 경우에도 사실성·개인정보·승인 기준은 동일하게 적용함.
